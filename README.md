## Publicar en GitHub Pages

1. Descomprime este ZIP.
2. Crea un repositorio público en GitHub o abre el repositorio donde quieres alojar la web.
3. En **Add file → Upload files**, sube `index.html` y este `README.md` a la raíz del repositorio. No subas el ZIP sin descomprimir.
4. Confirma la subida con **Commit changes**.
5. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Pulsa **Save**.
6. GitHub mostrará el enlace de la web cuando termine la publicación.

Si GitHub Pages ya estaba activado, basta con sustituir `index.html` y confirmar el cambio.

## Uso

Selecciona refuerzo o profundización y las categorías que correspondan. En el PRA, las cuatro situaciones principales se ajustan al artículo 33 de la Orden de ESO en su redacción de agosto de 2026; dentro de NEAE pueden concretarse las necesidades de apoyo.

Los cinco cuadros son editables y permiten copiar cada apartado o el texto completo. El TXT se descarga con un nombre basado en los tipos seleccionados: `PRA-…txt` o `Prof.-…txt`.

La web comienza sin categorías seleccionadas. No tiene guardado de borradores, impresión/PDF ni apartado ACS. Todo lo necesario para funcionar está incluido en `index.html`; no requiere instalación, claves, servidor propio ni conexión con la web original.
